### 2.3 一个 block 里发生什么（60 个 block 结构相同）

```
# 调制参数：图、文各一套，输入都是同一个 temb
[shift1, scale1, gate1, shift2, scale2, gate2] = Linear_img( SiLU(temb) )     3072 → 6·3072      T:650–652, :730, :686
[shift1', scale1', gate1', shift2', scale2', gate2'] = Linear_txt( SiLU(temb) )                 T:672–674, :734

# 注意力
h_img = LN(x_img) · (1 + scale1)  + shift1                                                       T:717
h_txt = LN(x_txt) · (1 + scale1') + shift1'
q_img, k_img, v_img = to_q(h_img), to_k(h_img), to_v(h_img)          # 3072 → 3072，有 bias     T:557–559
q_txt, k_txt, v_txt = add_q(h_txt), add_k(h_txt), add_v(h_txt)                                    T:562–564
拆成 24 头 × 128 → q、k 各做 RMSNorm(128)（图、文各一套）→ 套 RoPE                                T:569–595
Q = concat(q_txt, q_img)，K、V 同理（文字在前）→ 一次全注意力（只屏蔽文字 padding）                T:599–612, :551
拆回：attn_txt = 前 L_txt 个，attn_img = 后 6,889 个                                              T:619–620
x_img = x_img + gate1  · to_out(attn_img)                                                        T:623, :767
x_txt = x_txt + gate1' · to_add_out(attn_txt)                                                    T:627, :768

# FFN
x_img = x_img + gate2  · FFN_img( LN(x_img) · (1 + scale2)  + shift2  )                           T:771–774
x_txt = x_txt + gate2' · FFN_txt( LN(x_txt) · (1 + scale2') + shift2' )                           T:777–780
FFN(h) = W2 · GELU_tanh(W1 · h + b1) + b2         3072 → 12288 → 3072
```

### 2.9 冲突、未找到，以及和预设不一致的地方

1. **Qwen-Image-2.1 在 1328² 不是 6,889 个 token。** 每个 token 管 16 × 16 像素、64 维这点和 Qwen-Image 完全一样（§1.5），但 2.1 pipeline 把宽高向下取整到 32 的倍数（`pipeline_qwenimage21.py:640–642`），1328 → 1312，实际 82 × 82 = 6,724 个 token。要讲"两代每个 token 一样大"，可以说；要并排写 token 数，2.1 换 2.1 推荐尺寸（2048² → 16,384）。
2. **调制层占三分之一参数。** 60 层 × 两路的 `img_mod` / `txt_mod` 共 6.80B，占 20.43B 的 33.27%，比注意力（22.18%）还多。到 2.1 改成全模型共享一个调制，只剩 0.94%。
3. **调制向量只带时间，不带文字。** Qwen-Image 的 `temb` 只从 t 算（`T:207–229`）；SD3 的调制输入是 t + pooled 文字向量（SD3 §4，p4）。Qwen-Image 里文字只通过联合注意力进来。
4. **gate 有没有零初始化：未找到。** diffusers 没有自定义初始化，报告没提，官方训练代码没公开。片中不要说 "adaLN-Zero"。另外 Qwen-Image 的 gate 直接乘、没有 tanh（`T:767`）；2.1 的 gate 先过 tanh（`transformer_qwenimage21.py:641`）。
5. **norm_out 和 block 的切分顺序相反。** block 是 shift, scale, gate（`T:686`）；norm_out 是 scale, shift（`normalization.py:349`）。画图或手写对照代码时别套错。
6. **MSRoPE 报告说 2D，代码是 3 轴。** 代码有帧、行、列三个轴（16 / 56 / 56 维），文字在三个轴上取同一个号，从 `max(h//2, w//2)` 开始。Figure 8 (C) 是示意，坐标细节和代码对不上（图里 3 × 3 图像的文字从 (2, 2) 开始，按代码 3 × 3 时从 1 开始），片中按代码讲"从图的右下角外侧沿对角线排"即可。
7. **两份报告的 VAE 指标别混比。** SD3 Table 3 的 16 通道 PSNR 28.62、SSIM 0.86 是 SD3 自己的评测设置；Qwen-Image Table 2 里 SD-3.5-VAE 是 31.22 / 0.8839（ImageNet 256²、float32）。数据集和设置不同，不能放进同一张表。
8. **SD3 的 "d" 有两个意思。** §5.2.1 正文 d = latent 通道数；Figure 10 图注里 "depth d = 22" 的 d 是模型深度。引用"d = 22 时 8 通道和 16 通道差距可忽略"时要写清是深度。
9. **2.0 的 VAE 不是全面更好。** 2.0（f16c64）ImageNet PSNR 33.42 和 Qwen-Image（f8c16）恰好相同，SSIM 略高（0.9225 vs 0.9159）；文字集 PSNR 反而低（32.81 vs 36.63）。片中说"压得更狠、重建基本不掉"比"更好"稳。
10. **配置里有一个没用的字段。** `transformer/config.json` 写了 `pooled_projection_dim 768`，但 `QwenImageTransformer2DModel.__init__` 没有这个参数（`T:860–874`），不进模型。
11. **系统提示词的措辞报告和代码略有不同。** 报告 Figure 7："detailing the color, quantity, text, shape, size, texture, spatial relationships …"；pipeline：`"detailing the color, shape, size, texture, quantity, text, spatial relationships …"`（`P:175`）。只是词序，EP02 用不到。
12. **报告没写的结构细节**：FFN 激活函数、gate 初始化、调制向量的来源，都只能从 diffusers 源码讲（已标出处）。
13. **HF 原站本机解析不了。** 配置和权重头都来自 hf-mirror.com；repo sha 和 HF API 一致（`75e0b4be04f6…`、`d26bb61231c3…`），要和原站逐字比对，换一台能访问 huggingface.co 的机器再查。
